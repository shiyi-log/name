# 名字研究所

这是一个本地运行的四字公司名筛选工具。它保存完整的 8,105 个通用规范汉字，精确记录四字笛卡尔积的组合空间，并把符合规则的候选组合预先生成到 JSON 和 SQLite 数据库中。前端默认按综合评分降序分页展示全部规则候选，并把高分理由直接显示在列表中。

## 启动

在项目目录运行：

```bash
python3 -m http.server 4173
```

然后打开：`http://127.0.0.1:4173/`

不能直接双击 `index.html`，因为浏览器会阻止页面读取本地 JSON 文件。

## 数据与评分

- 完整字库：`data/characters-8105.json`
- 规则候选数据：`data/candidates.json`
- SQLite 数据库：`data/names.db`
- 数据库构建脚本：`build_database.py`
- 前端评分和排序：`app.js`

当前构建结果为 17,078 条规则候选。候选生成只使用一级常用字和二级规范字，三级规范字保留在完整字库中供检索，但不会进入规则候选，因此可以排除生僻字。去除三级规范字后的理论命名空间为 `6500^4 = 1,785,062,500,000,000`。

候选之间还会做两轮去重：同一对词元的正反排列只保留分高的那个（去掉「云开入云 / 入云云开」这类镜像重复），结构上完全相同的名字只保留一条。

`8105^4 = 4,315,310,765,550,625`，约 4.315 万亿个组合。这个数量不适合逐条物化到本地 SQLite：仅按每条 100 字节估算就超过 400 PB。数据库因此采用两层表示：`characters` 表完整保存 8,105 个字，`combination_space` 表精确保存各字库层级的组合数量，`name_candidates` 表保存所有由词元、模板和评分阈值筛出的规则内候选。

当前评分满分 100，保留一位小数：

| 维度 | 权重 |
| --- | ---: |
| 品牌感 | 28% |
| 读写与韵律 | 20% |
| 诗意与意象 | 20% |
| 独特性 | 18% |
| 注册启发分 | 14% |

评分逻辑在 `scoring.py`，构建脚本只负责调用它。每个维度都由多个连续信号加权得到，而不是按词元类别查表：

- **品牌感**：首词元的动作强度、结尾是否留白、词对稀有度、是否含行业套话。
- **读写与韵律**：真实拼音参与计算，包括四声起伏、平仄交替、连续同调、同音字、声母韵母重复、常用字占比、四字内重字。
- **诗意与意象**：意象词数量、意象字密度、季节与时辰、是否命中成词表、抽象词堆叠。
- **独特性**：字组二元组的稀有度分位、单字稀有度、用字是否全在高频区间。
- **注册启发分**：用字在 8105 字表中的频率秩、是否整词命中常见成语、是否含常见行业词。

分数区间会随候选池变化，因此前端的「优先研究 / 值得保留」分档按当前实际分布取分位（前 10% 与前 35%），不写死 90 分。

“注册启发分”只是根据用字常见度做的初筛，不代表工商登记或商标检索已经通过。正式确定名称前，仍需检查企业字号、商标、域名和社交账号。

### 依赖

拼音特征来自 `pypinyin`：

```bash
pip3 install pypinyin
```

## 增加候选

调整 `data/tokens.json`、评分规则或生僻字筛选边界后，重新运行：

```bash
python3 build_database.py
```

脚本会重新生成 `data/candidates.json` 和 `data/names.db`；前端会自动读取 JSON 数据并按评分重新排序。
