# 待统一复审候选池

用户顺序：先为全部8,105字补齐每字500个自然、不同的候选，再统一复审。不得用近义换字、倒序、强行拼词充数；参考文献只作核义与灵感参考。

- `candidates.jsonl`：直接创作的新候选，每行一名，保留释义、逐字角色、风险和原始提案JSON指针。全部 `deferred_full_review`、`counted_as_final:false`。
- `progress.json`：全部8,105字的生成进度，分别列出现有AI语义说明数、新候选数、缺口及旧复审数。进度不是最终质量验收。
- `manifest.json`：来源文件及SHA-256、合并计数、候选池和进度文件哈希。
- `baseline-audit-20261116.json`：只读正式库审计基线；正式库有变化时需要更新基线并重新合并。
- `merge_pool.py`：仅合并已写提案并做格式、字库、长度、正倒序基础排重，不生成名称、不调用模型接口、不改正式库。运行：`python3 data/generation-pool/merge_pool.py`。

本池采用R85开始的直接生成批次。旧正式库的质量复核未通过或待定项不因此自动恢复；当前池没有把旧审核报告作为新增名称批量导入。已知近似项保留原记录但暂不给新增生成进度，等待统一裁决。其余历史同名、语义近似与自然度完整复审仍待进行。

一个名称在各个不同汉字上各计一次生成进度，重复字不多计。每个字的目标始终是500，目标不因难字或当前产出缩小。
