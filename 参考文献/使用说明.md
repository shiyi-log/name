# 本地古籍参考库

资料用于查字词、诗句、典故、寓言、格言和文学意象，适合取名时回看出处。截至2026年11月15日，共整理111种书目或语料集；本次在原88种基础上新增23种，详见[扩充记录](扩充记录-2026-11-15.md)。正文以UTF-8纯文本保存，可离线阅读、复制和搜索。总集与选集有重叠，书目数和记录数都不等于独立作品总数。

先打开[完整目录](目录.md)选书，查看[本次扩充清单](本次扩充清单.md)了解新增资料。神话故事可从[原有故事出处索引](神话故事出处索引.md)和[补充索引](神话故事补充索引.md)进入，分别有22条和17条经本地原文核对的故事或形象。

## 文件怎样使用

- `正文/`：保留来源字形的阅读TXT；清理服务头尾、页码元数据和排版折行。来源本身可能繁简混排，古注与正文同存的版本在目录中另有说明。
- `简体检索/`：由阅读TXT经OpenCC转换，方便使用简体字搜索。转换不能统一所有异名、通假字、异体字和缺字。
- `原始/`：下载原档，包括JSON、TXT、ZIP、原README及可获得的许可文件，便于回查整理结果。
- [来源清单.json](来源清单.json)：逐文件记录下载地址、固定提交（适用时）、文件大小、SHA-256及来源说明。有问题的候选原档另标记为不进入阅读库。
- [书目索引.json](书目索引.json)：书名、分类、正文路径、来源路径和篇目范围，方便程序读取。
- [SHA256SUMS.txt](SHA256SUMS.txt)：本地文件校验清单，清单本身不计入。

TXT可用系统文本编辑器或VS Code打开。想找适合取名的字义，先查《尔雅》《说文解字》；想找诗词意象，先查《诗经》《楚辞》及诗词总集；想找仙山、神鸟、星河、人物典故，可配合两个神话故事索引搜索。

## 搜索原文

在项目根目录运行：

```bash
# 所有资料中搜索，默认最多显示20处上下文
python3 参考文献/工具/检索.py "望舒"

# 限定书名查询字义、诗句或故事
python3 参考文献/工具/检索.py "嘉" --book 尔雅 --limit 3
python3 参考文献/工具/检索.py "清风" --book 全宋诗 --limit 5
python3 参考文献/工具/检索.py "弄玉" --book 列仙传
python3 参考文献/工具/检索.py "瑶池" --book 穆天子传
python3 参考文献/工具/检索.py "定婚店" --book 续幽怪录
python3 参考文献/工具/检索.py "素心" --book 菜根谭 --limit 3
python3 参考文献/工具/检索.py "贾人" --book 郁离子 --limit 3
python3 参考文献/工具/检索.py "白玉堂" --book 三侠五义 --limit 3
```

搜索忽略字间的排版空白，结果含书名、行号、上下文和本地位置。选集和总集可能重复命中；出现某个字词不等于具有适宜取名的寓意，仍应回看完整章节。古书常用“姮娥”“形天”“乗”等字形，找不到时可尝试异名、原字形或更短关键词。

## 版本范围与已知缺陷

- 唐诗有4条、宋诗有23条空正文记录；重复记录按来源保留。《唐诗三百首》《宋词三百首》实际为366条、280条来源记录。
- 《花间集》当前开源源档实测497条，未按通行500首补齐；《南唐二主词》《纳兰性德诗词》均按选编记录保存。花间、南唐的现代注释仅留原档。
- 《元曲》11,057条包括散曲和杂剧曲文等记录，不等于11,057个独立剧目。《千家诗》含组诗分首共226条，与唐宋总库有重叠。
- 《文选》保存六十卷正文电子本，来源BASEEDITION为tls，未标为李善注本。《荀子集解》沿用来源题名，含序和32篇，但未核证全部集解注文齐备。
- 《资治通鉴》含胡三省注，阅读版保存294卷和前置提要；来源第295号为空壳，只留原ZIP。《战国策》是鲍彪校注十卷编次。
- 《太平广记》逐文件核对001至500卷；《夷坚志》仅甲乙丙丁戊各十卷，共五十卷，不是洪迈全书。《聊斋志异》为来源十二卷，实测496个篇题段，不据其他版本补齐。
- 《酉阳杂俎》候选原档有缺卷和混书问题，未纳入正文、简体检索及书目总数；保留原ZIP和[待核说明](来源/待核来源说明.md)。
- 《水浒传》是楔子加七十回本，不含一百回或一百二十回本后续内容。《春秋经》由《左传》附经提取，含哀公十五、十六年续经，共244个年标题。《尚书》阅读版为58篇，源ZIP另有第059号逸书材料。
- 《说文解字》的篆形、外字不能单靠TXT还原；《文字蒙求》也有符号代字。《玉台新咏》3处不可用的外字图片明确标记为缺字，未猜填。其他来源亦可能有缺字、错字、异文、繁简混排或作者归属争议。
- 2026年11月15日新增版本中，《菜根谭》仅按来源实测227段，《呻吟语摘》是摘本，《浮生六记》仅存四记；《三侠五义》不重复列为《七侠五义》，传统《狄公案》不混同高罗佩系列。问题候选来源与后续书目见[扩充记录](扩充记录-2026-11-15.md)。

## 来源与复现

主要来源为[chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)、[Project Gutenberg](https://www.gutenberg.org/)和[Kanripo](https://github.com/kanripo)。来源与许可分别记录：开源语料按固定提交核对Git blob；PG保留完整许可头尾；Kanripo保留固定提交ZIP和原始版本标记，未将无独立LICENSE的书库自行改标MIT或CC0。

[下载整理脚本](工具/下载整理.py)只写入本参考库，再运行会读取下载缓存并重新生成阅读版、总索引和校验清单；[神话批次脚本](工具/增补神话.py)也已接入总流程。基础下载使用Python标准库；生成简体检索版另需`opencc-python-reimplemented==0.1.7`，详见[工具依赖](工具/requirements.txt)。

```bash
# 已安装OpenCC依赖时
PYTHONDONTWRITEBYTECODE=1 python3 参考文献/工具/下载整理.py

# macOS上核对本地文件
cd 参考文献
shasum -a 256 -c SHA256SUMS.txt
```
