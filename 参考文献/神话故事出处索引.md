# 神话故事出处索引

这份索引依据本次下载的本地原文核对，供查故事、典故和取名意象使用。故事名称多为后人通用的概括，未必是古书原有篇名；下列“原句”采用简体检索版字形，适当合并排版空格。点击书名可打开保留来源字形的正文，篇卷和关键词用于定位。

古代神话常有不同叙述，本索引只说明本地版本记载了什么，不将各书异文拼成唯一故事。原文件、具体下载地址和版本说明见[目录](目录.md)及[来源清单](来源清单.json)。

## 怎样在本地找原文

在项目目录 `/Users/shiyi/取名` 打开终端，可使用随资料保存的检索工具：

```bash
python3 参考文献/工具/检索.py "女娲" --book 淮南子
python3 参考文献/工具/检索.py "姮娥" --book 淮南子
python3 参考文献/工具/检索.py "精卫" --book 山海经
python3 参考文献/工具/检索.py "形天" --book 山海经
python3 参考文献/工具/检索.py "扶摇" --book 庄子
```

工具优先搜索[简体检索版](简体检索)，忽略字间排版空白，并显示命中上下文和文件位置。繁简转换不能统一所有异名、通假字及缺字，因此找不到时可尝试本表列出的别名或较短关键词。取名时可先凭意象检索，再回看整段的寓意和情节。
